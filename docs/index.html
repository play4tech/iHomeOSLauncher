Questions you might have.

Which Android devices and versions are supported?

iHomeOS supports Android 13 and later (API 33+). It is optimized for silky 120fps refresh rates on modern displays and tested on Samsung One UI, Realme UI, Xiaomi HyperOS, OnePlus OxygenOS, Google Pixel devices, and standard AOSP distributions without requiring root or custom ROMs.

Where do ads appear?

Never on your home screen, desktop pages, wallpaper backdrop, dock, or folders. Small non-disruptive banner ads can appear only inside secondary menus (like settings), and purchasing iHomeOS Pro removes all advertisements permanently. Free users can also unlock customization features (such as icon resizing or App Library Only) by watching an optional rewarded ad. The launcher strictly conforms with Google Play’s Better Ads and Disruptive Ads policies.

What data does iHomeOS collect?

Zero personal telemetry. iHomeOS does not collect, harvest, or upload your app list, usage history, photos, or contacts to any external servers. All App Library categorization occurs 100% on-device. Anonymous diagnostic crash logs (via Sentry) help identify software bugs to improve stability. Please review our Privacy Policy for full compliance details.

How does the Liquid Glass refraction effect work?

Optimized for 120fps displays, iHomeOS calculates real-time optical light refraction, specular highlights, and chromatic aberration directly against your wallpaper backdrop using native GPU hardware acceleration and custom Skia shaders. A high-efficiency Gaussian blur fallback runs seamlessly on battery-saver mode or older chipsets.

  1. Liquid Glass optical refraction is calculated in real time using native GPU acceleration, optimized for silky smooth 120fps refresh rates on supported hardware. High-performance Gaussian blur fallback is provided on all devices.
  2. Requires Android 13 (API level 33) or later. Some custom manufacturer gesture systems may require setting iHomeOS as the default home app in system settings.
  3. iHomeOS Pro is a single lifetime purchase tied to your Google Play account. It automatically restores your ad-free and pro features on all devices with the same account.
  4. iHomeOS is an independent software application developed for Android devices.
